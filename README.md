# 가상오피스 — 사용설명서

전문 지식 없이도 켤 수 있게 썼습니다. 위에서부터 순서대로만 따라 하세요.

---

## 이 프로그램이 하는 일

대표님이 업무를 시키면 AI 직원 4명이 실제 회사처럼 나눠서 일합니다.

| 직원 | 역할 | 하는 일 |
|---|---|---|
| 이지혜 | 팀장 | 무엇을 알아봐야 하는지 지시서를 만들고, 마지막에 전체를 검수 |
| 재민 | 조사 담당 | 지시서의 1·2번 항목을 웹에서 검색해 조사 |
| 다은 | 조사 담당 | 지시서의 3·4번 항목을 웹에서 검색해 조사 |
| 승효 | 검증 담당 | 재민·다은의 조사가 믿을 만한지 검사, 부실하면 다시 시킴 |

그리고 **마지막 결정은 대표님이 합니다.** 팀장이 검수를 마치면 화면에
`승인합니다` / `보완 요청하기` 버튼이 나옵니다. 보완을 요청하면 팀이 다시 일합니다.

화면 왼쪽 위 사무실 그림에서 직원들이 자리에 있는지, 결과를 제출함에 내려놓는지
바로 보입니다. 밑에 한 줄로 "지금 누가 무엇을 하고 있는지"도 계속 나옵니다.

---

## 1단계 — 컴퓨터에서 켜보기

터미널(명령 프롬프트)을 열고, 이 폴더에서 아래를 한 줄씩 실행합니다.

```bash
npm install
```

다음으로 `.env.example` 파일을 복사해서 `.env` 라는 이름으로 만듭니다.

```bash
cp .env.example .env
```

`.env` 파일을 메모장으로 열면 이런 줄이 있습니다.

```
OPENROUTER_API_KEY=sk-or-v1-xxxxxxxx
```

`sk-or-v1-xxxxxxxx` 부분을 진짜 열쇠로 바꿔야 합니다. 열쇠 받는 방법:

1. https://openrouter.ai 접속 → 가입
2. 오른쪽 위 프로필 → Keys → Create Key
3. 나온 글자를 전부 복사해서 위 자리에 붙여넣고 저장

**이 열쇠는 절대 남에게 보여주지 마세요.** 돈이 나가는 열쇠입니다.

이제 실행합니다.

```bash
npm start
```

브라우저에서 `http://localhost:3000` 을 열면 사무실 화면이 나옵니다.

## 2단계 — 인터넷에 올리기 (남들이 쓸 수 있게)

돈 안 드는 곳 중 **Render.com**이 가장 쉽습니다.

1. 이 폴더를 GitHub에 올린다 (`.env` 파일은 절대 올리지 않는다 — `.gitignore`에 이미 막아뒀습니다)
2. render.com 가입 → New → Web Service → 방금 올린 GitHub 저장소 선택
3. 설정은 아래처럼
   - Build Command: `npm install`
   - Start Command: `npm start`
4. **Environment 탭**에서 값을 하나 추가
   - Key: `OPENROUTER_API_KEY`
   - Value: 위에서 받은 열쇠
5. Deploy 누르면 끝. 주소가 하나 생깁니다.

Railway.app도 방식이 똑같습니다.

---

## 3단계 — 잘 돌아가는지 확인하는 법

브라우저에서 주소 뒤에 `/api/health` 를 붙여보세요.
예: `http://localhost:3000/api/health`

```json
{"ok":true,"apiKeySet":true,"modelsUpdatedAt":"2026-07-30"}
```

- `apiKeySet`이 **true**여야 정상입니다. false면 열쇠가 안 들어간 것입니다.
- `modelsUpdatedAt`은 AI 목록을 마지막으로 점검한 날짜입니다.

## 정기적으로 해야 하는 관리 — 딱 하나

`config/models.json` 파일에 **어떤 AI를 쓸지** 적혀 있습니다.
문제는 여기 적힌 AI들이 **예고 없이 없어진다**는 것입니다. 특히 무료 AI가 자주 사라집니다.

### 무료 AI 확인 (2주에 한 번 권장)

1. https://openrouter.ai/collections/free-models 접속
2. `config/models.json` 의 `경제형_모델` 에 적힌 3개가 목록에 있는지 눈으로 확인
3. 없어진 게 있으면, 목록에 있는 다른 무료 AI 이름으로 바꿔 적고 저장

### 좋은 AI 확인 (한 달에 한 번 권장)

1. https://openrouter.ai/rankings 접속
2. 상위권 AI가 `품질_TOP5` 에 적힌 것과 많이 달라졌으면 바꿔 적기

**이름은 반드시 복사해서 붙여넣으세요.** 비슷하게 손으로 적으면 존재하지 않는
이름이 되어 작동하지 않습니다 (실제로 이런 일이 있었습니다).

파일을 저장하고 서버를 다시 켜면 바로 반영됩니다. 다른 파일은 건드릴 필요 없습니다.

### 무료 AI가 다 없어져도 서비스는 멈추지 않습니다

무료 AI 3개가 전부 실패하면 자동으로 좋은 AI로 넘어가서 계속 일합니다.
단, 이때는 **돈이 더 나갑니다.** 그러니 위의 2주 점검을 거르지 마세요.

## 돈이 얼마나 나가나

| 항목 | 대략 |
|---|---|
| 웹검색 | 1회당 약 $0.02 (조사 1건에 검색 여러 번) |
| 조사 (재민·다은) | 무료 AI를 쓰면 $0 |
| 검증·검수 (승효·이지혜) | 유료. 업무 1건당 대체로 몇백 원 수준 |

재조사·반려가 반복되면 그만큼 늘어납니다. 실제 요금은 openrouter.ai 사이트의
Activity 화면에서 확인할 수 있으니, 초반에는 자주 들여다보세요.

## 아직 안 만든 것 (다음에 할 일 순서)

1. 로그인, 사용 횟수 차감, 결제 연동
2. 무료 체험 횟수 제한 (지금은 제한이 없습니다)
3. 인플루언서 추천 링크와 정산
4. 며칠 안 들어온 사용자에게 알림 보내기
5. 이미지 만들기 기능
6. 시장조사 외의 업무 (콘텐츠 작성, 발주서 등)

## 파일이 각각 뭔지

| 파일 | 설명 |
|---|---|
| `server.js` | 직원들이 일하는 순서가 적혀 있는 핵심 파일. AI에게 주는 지시문도 여기 있습니다 |
| `config/models.json` | 어떤 AI를 쓸지 적은 목록. 위의 정기 관리에서 고치는 파일 |
| `public/index.html` | 대표님이 보는 사무실 화면 |
| `public/landing.html` | 홍보용 소개 페이지 (기존 파일 보관) |
| `.env` | 열쇠를 넣어두는 파일. 절대 공유·업로드 금지 |

**가장 중요한 자산은 `server.js` 안의 지시문 문장들입니다.**
"AI를 만드는 게 아니라 AI를 제대로 부리는 절차를 판다"는 것이 이 사업이므로,
실제 질문을 계속 넣어보면서 이 문장을 다듬는 게 제일 중요한 작업입니다.

## 뭔가 안 될 때

| 증상 | 원인과 해결 |
|---|---|
| "AI 사용 열쇠가 설정되지 않았습니다" | `.env` 파일에 열쇠가 없습니다. 1단계 다시 확인 |
| 화면이 계속 "진행 중"에서 안 바뀜 | 정상일 수 있습니다. 업무 1건에 2~5분 걸립니다 |
| 오류 메시지에 402 / insufficient | openrouter.ai 잔액이 없습니다. 충전 필요 |
| 오류 메시지에 429 | 무료 AI 사용량 한도입니다. 잠시 뒤 다시 시도 |
| 계속 실패 | `config/models.json`의 AI 이름이 없어진 것일 수 있습니다. 위 정기 관리 참고 |
